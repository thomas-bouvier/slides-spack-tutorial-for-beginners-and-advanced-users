# slides-spack-tutorial-for-beginners-and-advanced-users

This Numpex tutorial related to software packaging will get both beginners and more advanced users up and running with the Spack package manager. The tutorial will introduce Spack installation, base commands, specifications, configs, and environments. We are also going to cover more advanced topics, like using the official Numpex binary cache hosted at ghcr.io/numpex/spack-stack and development workflows. A practical goal of the tutorial is to compile and run a functional mini Gysela app. No prior experience with Spack is required.

The webinar will be organized as a hands-on session so users can directly experiment with Spack. We will provide accounts on Grid'5000 for all attendees. If you already have a CINES account giving you access to the Adastra supercomputer, you will be able to follow along using this HPC platform instead of Grid'5000. We will be available to assist you and answer questions via video and chat.

Note that this tutorial is part of the Numpex software integration strategy backed by the Exa-DI WP3 team. Our ambition is to have most Numpex-related libraries packaged in Spack, make Spack-based deployment part of every developer’s arsenal, and work with computing centers to make Spack-based user-level software deployment as frictionless as possible.
